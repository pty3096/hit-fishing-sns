# 글·검색 공유 링크 — 0.23.0

글 상세, 조황 검색, 커뮤니티, 장터 목록에서 ‘링크 복사’를 제공합니다. 로그인하지 않아도 현재 볼 수 있는 공개 화면에서 사용할 수 있습니다. 메시지 전송·SNS 게시·주소 단축 서비스로 자동 연결하지 않으며 링크를 붙여넣어 전달하는 일은 사용자가 진행합니다.

## 사용 방법

글 상세에서는 해당 글 주소를, 목록에서는 현재 적용된 검색 조건을 복사합니다. 아직 찾기 버튼을 누르지 않은 새 입력은 포함하지 않습니다. 게시판·검색어·지역·어종·낚시 방식·출조일·가격·판매 상태·공개 작성자 조건 중 해당 화면이 지원하는 조건만 유지합니다.

자동 복사가 성공하면 복사 완료 안내를 표시합니다. 브라우저 권한이나 기능 지원으로 복사할 수 없으면 읽기 전용 링크 입력창과 직접 선택·복사 안내를 표시합니다. 이때 복사 성공이라고 안내하지 않습니다. 닫기를 누르면 입력창을 숨깁니다. 클립보드 내용은 읽지 않고 버튼을 누를 때만 쓰기를 요청합니다. [Clipboard.writeText 문서](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard/writeText)를 참고했습니다.

PC 로컬 주소는 다른 기기에서 열 수 없다는 안내를 함께 표시합니다. 휴대폰 시범 주소는 접속 인증·PC 실행 상태에 의존한다는 기존 조건을 안내합니다. 이 기능으로 고정 공개 도메인이나 상시 운영 서버가 생기는 것은 아닙니다. 실제 운영 주소가 연결되면 같은 주소를 기준으로 링크를 만듭니다.

## URL 구성·공개 범위

현재 접속 출처의 루트 경로와 허용된 해시 경로만 사용합니다.

- `#post/:id`: 양의 안전 정수 글 ID만 보존합니다.
- `#search`: q, fish, region, method, date_from, date_to.
- `#community`: q, 공개 author 번호.
- `#market`: status, q, region, min_price, max_price, 공개 author 번호.

원래 URL의 최상위 검색 문자열과 인증·추적·페이지 커서 등 허용하지 않은 매개변수는 제외합니다. URL 사용자 이름·비밀번호도 결과에 넣지 않습니다. 내 글 관리·개인 저장·알림·개발 메일함·로그인·인증·비밀번호 재설정·작성/수정 화면은 공유 대상에서 제외합니다. URL에 포함된 검색어는 사용자가 선택한 공개 검색 조건이므로 복사 전에 내용을 확인할 수 있습니다.

공유 링크는 인증이나 조회 권한을 부여하지 않습니다. 받는 사람이 로그인·차단·숨김 등 기존 공개 범위 검사에 따라 다른 결과를 볼 수 있습니다. 글이 삭제되거나 숨겨지면 기존 오류 안내를 표시합니다. 새 공유 토큰·공유 DB·외부 서비스·접근 권한 변경은 없으며 스키마는 11입니다.

## 검증

자동 검사 55개 통과. 글 ID 정리, 원래 URL 검색 문자열·사용자 정보 제거, 조건과 특수문자 보존, 0원 가격 보존, 개인 목록·인증 경로 및 잘못된 주소 제외를 확인했습니다.

Chrome 화면 검사 8개 통과. 버튼 클릭 전 복사 없음, 적용된 조건과 아직 검색하지 않은 입력 구분, 복사 URL 재접속 후 검색 복원, 글/커뮤니티/장터 링크, 복사 허용/거절 응답, 거절 시 직접 복사 입력·성공 오인 안내 없음·닫기, 320·390px 가로 넘침 없음을 확인했습니다. 클립보드 쓰기는 테스트 대체 객체를 사용했고 실제 사용자 OS 클립보드를 읽거나 덮어쓰지 않았습니다.

별도 로컬 앱의 기존 개발 검증 커뮤니티 글에서 버튼 표시 화면도 저장했습니다. 실제 개발 계정·게시물·사진·댓글을 수정하지 않았습니다. 실제 아이폰 Safari의 클립보드 권한·선택·붙여넣기와 다른 기기에서의 접속은 별도 확인이 필요합니다.
