# 시범 접속 미해결 기록 — 2026-11-20

## 확인한 사실

사용자는 이메일 접속 인증 뒤 앱 외형은 보이나 데이터 요청에 연결 오류가 난다고 반복 보고했습니다. PC에서 관찰한 인증 탭은 인증번호 입력 화면 또는 별도 MyIdentity SSO의 ‘Authentication was cancelled or timed out’ 화면에 있었습니다. 앱이 정상 동작하는 인증 후 세션을 직접 관찰하지 못했습니다. 사용자의 인증번호·쿠키·JWT는 수집하지 않았습니다.

이전 단계의 기본/화면 검사와 로컬·미인증 진입점 진단 통과는 실제 아이폰의 인증 후 동작 통과가 아닙니다. 2026-11-20 재점검에서는 시범 서버가 종료돼 있었고 이전 임시 주소의 기초 진단 7개가 모두 실패했습니다. 이는 이전 서버 정상 응답 기록과 시간대가 다른 관찰입니다. 로컬 개발 앱만 다시 실행했습니다. 외부 시범 접속은 미해결 상태로 둡니다.

## 관련 공개 제보와 한계

[cloudflare/cloudflared #1752](https://github.com/cloudflare/cloudflared/issues/1752)에는 이메일 보호 Quick Tunnel에서 인증 직후 세션이 빠르게 만료되고 GET이 로그인으로 되돌아가며 다른 요청은 401로 거부되는 사례가 보고돼 있습니다. 2026.11.0에서도 유사 사례가 댓글로 보고돼 있습니다. 이 저장소에서 사용하는 cloudflared는 재점검 당시 2026.10.5입니다.

이는 사용자가 겪은 ‘화면 일부 로드 후 데이터 요청 실패’와 유사한 후보입니다. 공개 사용자 제보는 우리 접속의 원인을 확정하거나 공급자의 수정 완료를 증명하지 않습니다. 따라서 추가 인증번호 요청이나 임의 코드 변경을 해결책으로 반복하지 않습니다. 현재 미인증 리다이렉트 검사만으로 이메일 보호의 실사용 성공을 판정하지 않습니다.

## 다음 확인 기준

인증 후 첫 화면뿐 아니라 60초 이상 지난 뒤 조회·로그인·글 등록·새로고침이 유지돼야 실사용 접속을 통과 처리합니다. 서버 진단·PC 브라우저·실제 아이폰 결과를 구분합니다. 외부 보호를 없애거나 개발 메일함·개발 DB를 그대로 공개하는 방식으로 전환하지 않습니다.

로컬 검증은 계속 가능하며 외부 실기기 점검은 안정적인 호스팅/고정 접속 경로가 필요합니다. [검토 가능한 전환안](41_FIXED_HOSTING_PROPOSAL.md)을 준비했지만 서비스 생성·결제·공개 배포는 수행하지 않았습니다.
