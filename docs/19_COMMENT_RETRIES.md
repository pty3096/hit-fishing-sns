# 댓글 전송 재시도 — 0.8.1

댓글 전송 후 응답만 끊긴 경우 같은 게시물 화면에서 같은 내용을 다시 전송하면 기존 댓글 번호를 돌려줍니다. 댓글을 새로 만들지 않습니다. 같은 요청이 동시에 도착해도 댓글·요청 기록은 한 번에 저장합니다.

전송에 실패하면 댓글 입력을 유지하고 같은 요청 번호로 재시도합니다. 전송 중에는 입력란을 읽기 전용으로 두어 작성 내용이 바뀌지 않게 합니다. 성공 응답을 받으면 입력과 요청 번호를 초기화합니다. 성공 후 같은 문구를 다시 쓰는 것은 새 댓글로 취급합니다.

## 저장과 권한

계정별 무작위 요청 번호·게시물과 댓글 내용의 SHA-256 지문·댓글 번호를 저장합니다. 원문을 요청 기록에 중복 저장하지 않습니다. 요청 번호와 지문은 서버 재시작 후에도 유지됩니다. 같은 번호로 다른 댓글이나 다른 게시물에 전송하면 충돌로 안내합니다.

삭제·숨김된 댓글은 같은 요청 번호로 재생성하지 않습니다. 원글 삭제·차단 시에는 기존 공개 범위 검사를 먼저 적용합니다. 로그인·이메일 인증·이용 제한 검사도 그대로 적용합니다. 탈퇴 시 본인의 댓글 요청 기록은 삭제됩니다. 스키마 버전은 7입니다.

## 범위와 사용법

전송에 실패하면 화면을 유지한 채 다시 시도해주세요. 화면을 닫거나 새로고침하면 요청 번호를 복원하지 않으므로 먼저 댓글 목록에서 등록 여부를 확인해주세요. 댓글 임시 저장은 이번 변경 범위에 포함하지 않습니다. 요청 번호가 없는 기존 API 호출은 이전 방식과 호환됩니다.

외부 앱 인증이 만료되거나 실제 아이폰의 네트워크가 바뀌는 상황은 실기기 확인이 필요합니다. 자동 재시도·무한 재전송은 하지 않습니다.

## 검증

자동 검사 28개 통과. 서버 재시작 후 재전송, 동일 요청 동시 전송, 다른 계정의 동일 번호, 다른 게시물·내용 충돌, 잘못된 번호, 비로그인 요청, 삭제·숨김·차단 후 재시도와 탈퇴 시 기록 삭제를 검사했습니다. 실제 아이폰에서 응답을 끊는 검증은 아직 진행하지 않았습니다.

적용 전 로컬·시범 데이터베이스를 각각 백업하고 무결성 검사를 완료했습니다. 원본 계정·게시물·사진·백업을 저장소에 올리지 않습니다.
