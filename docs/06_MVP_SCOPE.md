# 히트 HIT 첫 버전 개발 범위

상태: 사용자가 단계별 개발 진행에 동의한 후 정리한 신규 개발 기준. 이전 설계 원본의 복원본이 아닙니다.

## 목표와 제공 방식

낚시인이 사진과 조황을 기록하고 다른 낚시인의 기록을 찾아 소통할 수 있는 첫 버전을 만듭니다. 모바일 중심 반응형 웹으로 시작하며 PC에서도 같은 계정과 공식 로고를 사용합니다. 앱스토어 배포는 후속 단계입니다.

첫 사용 흐름: 피드 열람 → 가입·로그인 → 조황 작성 → 게시물 상세 → 댓글·팔로우 → 내 프로필에서 기록 확인.

## 첫 버전 기능과 완료 기준

| 기능 | 구현 기준 | 완료 확인 |
| --- | --- | --- |
| 계정 | 이메일 가입·로그인·로그아웃·비밀번호 재설정 | 새 계정과 기존 계정으로 로그인하고 재설정 가능 |
| 프로필 | 닉네임·소개·프로필 사진 수정, 게시물·팔로워·팔로잉 목록 | 새로 접속해도 변경 내용 유지 |
| 조황 작성 | 사진 1~5장, 본문, 어종, 시·군·구 지역, 낚시 방식, 출조일 | 작성 후 피드·상세·프로필에 같은 기록 표시 |
| 수정·삭제 | 작성자만 자신의 게시물 수정·삭제 | 다른 계정의 요청은 서버에서 거부 |
| 피드 | 전체 최신순·팔로잉 최신순, 추가 불러오기 | 중복 없이 다음 게시물 표시, 빈 목록·실패 상태 제공 |
| 상세·소통 | 좋아요 취소, 댓글 작성·본인 댓글 삭제, 팔로우 취소 | 두 계정 사이의 변경이 저장되고 수치에 반영 |
| 조황 검색 | 어종·지역 필터, 필터 해제 | 두 조건을 함께 적용하고 결과 없음 상태 표시 |
| 신고·차단 | 게시물·댓글·계정 신고, 차단·해제 | 신고 접수 확인, 차단 계정의 게시물·댓글 숨김 및 상호작용 제한 |
| 운영 | 제한된 운영자만 신고 조회·조치 | 콘텐츠 숨김과 계정 이용 제한, 조치 기록 보존 |

비로그인 사용자는 공개 피드·검색·상세·프로필을 열람하고, 작성·소통 기능을 선택하면 로그인으로 안내합니다. 탈퇴 및 사용자 데이터 삭제 절차는 공개 출시 전에 구현하고 검증합니다.

## 화면 목록

1. 홈: 로고, 전체·팔로잉 탭, 조황 카드, 작성 진입
2. 검색: 어종·지역 필터, 결과 목록
3. 조황 상세: 사진, 조황 정보, 작성자, 좋아요·댓글, 신고·차단
4. 조황 작성·수정: 사진 선택·미리보기·제거, 조황 입력, 저장 진행·실패 안내
5. 내 프로필·다른 사용자 프로필: 소개, 게시물, 팔로우 상태, 팔로워·팔로잉 목록
6. 프로필 편집
7. 회원가입·로그인·비밀번호 재설정
8. 설정: 로그아웃, 차단 목록·해제, 탈퇴
9. 운영자 신고 관리: 신고 목록·상세·조치

모바일 하단 메뉴는 홈·검색·작성·프로필로 시작합니다. PC에서는 같은 기능을 상단 또는 측면 메뉴에 배치합니다. 내비게이션 배치는 새 화면 설계에서 구체화합니다.

## 기록할 데이터

- 사용자와 프로필
- 조황 게시물과 사진: 작성자, 본문, 어종, 지역, 낚시 방식, 출조일, 생성·수정 시각
- 댓글, 좋아요, 팔로우
- 신고, 차단, 운영 조치 기록

정확한 낚시 지점 좌표는 첫 버전에 수집하지 않습니다. 사진 업로드 시 위치를 포함한 메타데이터를 제거하고 파일 형식·크기와 실제 파일 내용을 검증합니다. 구체적인 용량 제한과 저장 서비스는 개발 기반 단계에서 결정합니다.

## 후속 버전

숏폼 영상, 상세 지도·낚시 포인트, 출조 예약·결제, 장터, 랭킹, 실시간 채팅, 푸시 알림은 첫 버전 범위에서 제외하고 사용자 피드백에 따라 순서를 정합니다.

## 개발 순서

1. 이 범위를 기준으로 화면과 사용 흐름 설계
2. 기술 스택·저장소·인증 방식 선정과 데이터·접근 권한 설계
3. 로그인 → 조황 작성·열람 → 프로필까지 한 흐름 연결
4. 댓글·좋아요·팔로우·검색 추가
5. 신고·차단·운영·탈퇴 구현
6. 두 계정과 실제 휴대폰으로 검증 후 제한된 시범 운영

## 공개 전 확인

실제 데이터 저장, 작성자 권한, 비로그인 접근, 업로드 검증, 신고·차단, 탈퇴, 로딩·빈 목록·오류·재시도, 모바일·PC 화면, 백업·복원 절차를 확인합니다. 약관·개인정보 처리방침과 운영 담당자를 준비합니다. 샘플 데이터 화면은 시연용으로 표시하며 실제 서비스 완성과 구분합니다.
