# 휴대폰 시범 사용 점검 준비

상태: 준비 완료, 실제 휴대폰 점검은 미실행. 기종·브라우저와 접속 환경을 확인한 후 진행합니다. 이전 320·390px 화면 검사는 PC 브라우저의 화면 크기 검사이며 실기기 검사가 아닙니다.

## 지금 확인할 수 있는 것

PC에서 `npm start`로 앱을 실행하고, 다른 터미널에서 `npm run check:local`을 실행합니다. 별도 포트를 사용하면 `npm run check:local -- http://127.0.0.1:포트`로 점검합니다.

이 명령은 실행 상태·DB 응답, 개발 메일·인증 설정, 비로그인 상태, 메일함 접근 제한, 화면 파일 5개, 보안 헤더 등 총 10개를 읽기 전용으로 확인합니다. 계정이나 게시물을 만들거나 메일을 보내지 않습니다. 실패하면 종료 코드 1을 반환합니다. 기본 주소는 `http://127.0.0.1:3000`이며 로컬 HTTP 주소만 허용합니다.

2026-11-17 현재 실행 중인 PC 앱에서 10개 모두 통과했습니다. 이 결과는 휴대폰·메일 발송·공개 배포의 성공을 의미하지 않습니다.

## 휴대폰 접속 전제

현재 앱은 PC의 루프백 주소에만 연결되어 있습니다. 휴대폰에서 `127.0.0.1`을 열면 휴대폰 자신을 가리키므로 이 PC 앱으로 접속되지 않습니다. 같은 와이파이에 연결해도 현재 설정으로는 접속할 수 없습니다.

개발용 메일함이 있는 상태로 PC의 외부 접속을 열지 않습니다. 실기기 접속은 기종을 확인하고 연결 방식을 정한 뒤 준비합니다. 공개 HTTPS 시범 서버를 사용할 경우에는 도메인·서버·SMTP 연결과 별도 시범 계정이 필요합니다. 아직 서비스 선택·결제·공개 주소 생성은 하지 않았습니다.

실제 휴대폰 접속 후 아래 항목마다 `통과 / 실패 / 미실행`을 기록합니다. 테스트 글 제목에는 `[시범 점검]`을 넣고, 본인 확인용 계정·개인정보 없는 사진을 사용합니다. 개인정보가 있는 사진이나 실제 비밀번호를 점검 기록에 첨부하지 않습니다.
