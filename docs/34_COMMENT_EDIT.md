# 본인 댓글 수정 — 0.22.0

본인이 작성한 댓글의 ‘댓글 수정’을 누르면 해당 댓글 안에서 내용을 고칠 수 있습니다. 조황·커뮤니티·장터 댓글에 같은 규칙을 적용합니다. 로그인·이메일 인증을 완료한 정상 계정이 이용합니다.

## 사용 방법

- 수정 내용은 앞뒤 공백을 제외한 1~300자입니다. 빈 내용·300자 초과는 거절합니다.
- 댓글 수정 저장을 누르면 기존 댓글 본문만 바꿉니다. 취소는 수정 창을 닫고 기존 표시로 돌아갑니다.
- 편집 중에는 같은 댓글의 수정·삭제 버튼을 비활성화합니다. 다른 댓글 편집·삭제나 새 댓글 등록은 먼저 수정 저장 또는 취소하도록 안내합니다. 작성 중이던 새 댓글 내용은 지우지 않습니다.
- 편집 입력은 임시 저장하지 않습니다. 내용 변경 후 다른 화면으로 이동하면 임시 저장 없이 이동할지 확인합니다. 페이지 새로고침·닫기에는 브라우저의 이탈 확인을 사용합니다.
- 저장 중에는 입력·저장·취소를 잠시 제한합니다. 이 상태에서 다른 화면으로 이동하면 이동 후에도 수정이 반영될 수 있다고 안내합니다. 늦은 저장 응답으로 새 작성 화면이나 입력을 변경하지 않습니다.

연결 실패 시 편집 내용과 오류 안내를 유지합니다. 저장 응답이 끊겼다면 서버 반영 여부가 불확실할 수 있어 목록을 다시 확인하거나 같은 내용으로 재시도할 수 있습니다. 취소는 이미 서버에 반영된 수정까지 되돌리는 기능이 아닙니다. 댓글 수정 이력·별도 수정 시각 표시는 이번 범위에 포함하지 않습니다.

## API·권한

`PATCH /api/comments/:id`에 `{ "body": "수정 내용" }`을 전송합니다. 응답은 기존 댓글 id와 정리된 본문입니다. 비로그인은 401, 작성자가 아니면 403, 삭제되었거나 현재 보이지 않는 댓글·원글은 404로 처리합니다. 기존 JSON·요청 출처·이메일 인증·이용 제한 검사를 유지합니다.

본인의 댓글이어도 댓글·원글 숨김, 차단 관계, 이용 제한 상태로 현재 접근할 수 없다면 수정할 수 없습니다. 운영자라고 다른 사람의 댓글 본문을 수정할 수 있는 기능은 추가하지 않았습니다.

기존 댓글 ID·작성자·원글·등록 시각을 유지하고 본문만 UPDATE합니다. 같은 내용으로 반복 저장해도 새 댓글이나 알림을 생성하지 않습니다. 댓글 등록의 request_id 기록을 바꾸지 않으므로 이전 등록 요청 재전송은 같은 댓글을 찾고 수정 내용을 덮어쓰지 않습니다. 알림·메일·푸시를 새로 보내지 않습니다.

화면은 변경된 댓글 본문만 문자로 갱신하고 목록 전체를 다시 불러오지 않아 열린 댓글 페이지와 새 댓글 입력을 보존합니다. HTML 태그를 입력해도 코드가 아닌 문자로 표시합니다. DB 스키마는 기존 11이며 새 테이블·계정·자료 이동은 없습니다. 동시에 여러 곳에서 수정하면 마지막 저장이 반영되며 충돌 병합 기능은 없습니다.

## 검증

자동 검사 54개 통과. 비로그인·타인 수정 거절, 요청 출처 검사, 공백·길이 검증, ID·등록 시각 유지, 반복 수정·원래 등록 요청 재시도 후 수정 본문 유지, 알림 수 불변, 숨김·차단·인증 전·이용 제한·삭제 후 거절, 조황/커뮤니티/장터 댓글 수정을 확인했습니다.

Chrome 화면 검사 7개에서 취소·연결 실패 후 입력 유지·재시도 저장·수정 후 HTML 문자 표시·새 댓글 입력 보존·이동 취소·저장 중 다른 화면으로 이동한 뒤 새 조황 입력 보존, 비로그인 수정 버튼 미노출, 320·390px 가로 넘침 없음을 확인했습니다. 검증용 댓글은 별도 임시 DB에만 생성·수정했습니다. 실제 개발·휴대폰 시범 계정과 글·댓글을 변경하지 않았습니다.

캡처 이미지는 테스트용 댓글 편집 화면입니다. 실제 아이폰 Safari의 키보드·터치·이탈 확인 동작은 별도 점검이 필요합니다.
