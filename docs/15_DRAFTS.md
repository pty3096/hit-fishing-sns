# 글 임시 저장과 이어쓰기 — 0.7.0

조황 작성·수정 화면에서 제목, 어종, 지역, 낚시 방식, 출조일, 이야기를 입력하면 브라우저의 이 탭에 임시 저장합니다. 같은 계정으로 같은 작성 화면에 다시 들어가면 `이어쓰기` 또는 `임시 글 삭제`를 선택할 수 있습니다. 이어쓰기를 선택하지 않고 글 입력을 시작하면 새 내용으로 임시 글을 교체합니다.

- 계정마다 신규 글 1개, 수정 글은 게시물마다 1개를 보관합니다.
- 마지막 입력 이후 24시간이 지나면 다음 조회에서 만료 처리합니다.
- 새로고침 후에도 남지만 일반적인 탭 종료 시 삭제됩니다. 브라우저 세션 복구 기능이 임시 저장을 되살릴 수 있으므로 공용 기기에서는 로그아웃해주세요.
- 사진 파일·기존 사진 삭제·순서 변경은 보관하지 않습니다. 사진을 다시 선택·확인해야 합니다.
- 서버와 다른 기기에는 임시 글을 전송하지 않습니다. 비밀번호·이메일·사진 데이터도 임시 글에 저장하지 않습니다.
- 글 등록·수정 성공, 로그아웃·탈퇴 시 해당 계정의 임시 글을 정리합니다.
- 저장 공간을 사용할 수 없으면 실패 안내를 표시합니다. 필요한 글을 복사한 뒤 이동해주세요.

변경 내용이 있는 상태로 앱 안의 다른 화면으로 이동하면 확인창을 표시합니다. 취소하면 사진 선택과 글을 그대로 유지합니다. 새로고침·탭 닫기에도 브라우저가 이탈 안내를 표시하도록 요청하지만, 모바일 앱 강제 종료 등에서는 브라우저가 표시하지 않을 수 있습니다. 임시 저장은 정식 등록을 대신하지 않습니다.

## 검증

자동 검사: 새 저장소 인스턴스에서 복원, 계정·게시물 격리, 텍스트 허용 목록, 만료, 계정별 정리, 깨진 데이터·저장 차단 처리. 기존 검사와 합쳐 23개 통과.

로컬 브라우저: 제목·이야기 입력 → 홈 이동 확인 → 취소 시 주소와 입력 유지 → 이동 승인 → 작성 화면 재진입 → 이어쓰기 선택 → 원문 복원 확인. 실제 게시물은 추가하지 않았습니다.

실제 모바일 기기의 백그라운드 종료·브라우저 세션 복구 동작은 아직 검증하지 않았습니다.
