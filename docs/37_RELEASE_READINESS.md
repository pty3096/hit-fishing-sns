# 첫 버전 출시 준비 상태 — 0.28.0

이 문서는 현재 저장소의 구현·시험 범위입니다. 공개 서비스 출시 완료를 뜻하지 않습니다. 원래 설계가 복원되지 않은 내용은 신규 구현 기준이며, 출처와 누락은 SOURCE_STATUS.md를 따릅니다.

## 구현하고 로컬·자동 검사로 확인한 범위

| 영역 | 상태 |
| --- | --- |
| 계정·인증 | 가입·로그인·로그아웃·개발용 메일 인증·비밀번호 재설정·탈퇴, 같은 탭 작업 복귀 |
| 프로필 | 닉네임·소개·사진, 사진 선택 취소·실패 복구·공개 프로필 |
| 게시물 | 조황·커뮤니티·장터 작성·수정·삭제·다중 사진 순서·대표 사진, 소유자 검사 |
| 탐색 | 최신·팔로잉·저장 목록, 어종·지역·방식·기간·본문 검색, 닉네임 찾기, 내 글 관리 |
| 소통·운영 | 좋아요·댓글 작성/수정/삭제·팔로우·알림·신고·차단·관리자 조치 |
| 사용성 | 텍스트 임시 저장·이탈 안내·전송 재시도·공유 링크·모바일 인증 입력 |
| 디자인 | 확정 UI v1.1 합성 시안 기준 PC/모바일·같은 물고기 로고, 개별 편집 원본 미확보 |
| 실행 준비 | 단일 서버 SQLite·백업/복원·Docker·Caddy·운영 설정 검사·CI |

자동 검사 57개와 별도 Chrome 화면 검사 15개가 통과했습니다. 시험용 임시 DB와 브라우저를 사용하며 실제 개발·시범 계정 데이터는 변경하지 않습니다. 320·390px 등 모바일 너비 검사는 실제 아이폰 Safari 기기 검증과 구분합니다. 버전별 원격 검사는 GitHub Actions 결과를 따릅니다.

## 직접 확인이나 외부 연결이 남은 항목

- 아이폰 Safari에서 이메일 인증으로 보호된 시범 접속 로그인, 사진 보관함 선택, 키보드와 홈 화면 설치 확인. 일회용 인증번호는 사용자가 기기에 직접 입력합니다.
- 실제 SMTP 서비스 연결·발신 도메인 설정과 외부 메일 수신·실패 처리 확인.
- 운영 서버·도메인·HTTPS·영구 볼륨·외부 백업 보관 연결과 복구 훈련.
- 실제 운영자 계정 지정, 운영 담당자·문의 창구·이용 정책·개인정보 처리방침 확정.

서버·도메인·SMTP 계정이 없는 상태에서 공개 배포 완료로 표시하거나 임의로 유료 계약하지 않습니다. 자격 정보는 대화나 저장소에 올리지 않고 해당 서비스에서 직접 연결해야 합니다.

## 범위가 다른 후속 기능

숏폼과 선상예약은 준비 중 화면입니다. 실제 동영상 업로드/재생 파이프라인·예약 재고·결제는 구현하지 않았습니다. 장터는 상품 게시판이며 결제·중개·배송·실시간 채팅 기능은 없습니다. 지도는 지역 단위 조회이며 정확한 개인 낚시 포인트 수집·공개는 제공하지 않습니다. 푸시 알림·앱스토어 배포도 미구현입니다. 크리에이터 전용 기능은 사용자 요청으로 제외했습니다.

## 글 전송 보호

0.27.0에서 전송 시작 시 사진·입력·선택·삭제 및 임시 글 복원 버튼을 잠급니다. 이동 시 전송 중임을 안내하며 텍스트 임시 저장은 전송 직전 값을 사용합니다. 실패하면 기존 입력·사진을 유지하고 편집을 다시 허용합니다. 같은 내용의 재시도는 기존 요청 식별자를 유지합니다. 화면을 나간 경우 다른 화면의 입력 상태를 변경하지 않습니다. 사진은 임시 저장되지 않습니다.

## 0.28.0 사진 순서와 기기 보고

사진 미리보기의 앞으로/뒤로 버튼으로 순서를 바꾸고 첫 사진을 대표로 사용합니다. 저장 시 서버의 사진 위치 순서로 반영합니다. 사진과 순서 변경은 텍스트 임시 저장에 포함되지 않습니다. 사용자가 아이폰 시범 접속 완료를 보고했으며 앱 자체 로그인·인증과 사진 선택 등 개별 기기 결과는 여전히 확인 대기입니다.
