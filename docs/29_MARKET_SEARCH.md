# 장터 상품 검색·가격 필터 — 0.18.0

장터 검색 양식에서 상품명·설명, 거래 지역, 최저·최고 가격을 입력해 원하는 상품 글을 찾습니다. 기존 확정 로고·색상·장터 카드 구성을 재사용합니다. 전용 크리에이터 기능은 추가하지 않습니다.

## 사용 방법

- 상품명 또는 상품 설명에 입력한 검색어 전체가 포함된 글을 찾습니다. 검색어는 앞뒤 공백을 제외한 최대 80자입니다. 여러 단어를 자동으로 분리하거나 유사어를 추천하는 검색은 아닙니다.
- 기존 거래 지역 부분 검색과 전체/판매 중/거래 완료 조건을 함께 적용합니다.
- 최저·최고 가격은 0~1,000,000,000원의 정수이며 경계 금액도 포함합니다. 한쪽만 입력하면 해당 방향만 제한합니다. 빈 값은 가격 제한 없음입니다.
- 최고 가격을 0원으로 입력하면 나눔 글을 찾습니다. 최저가 0원 하나만 있으면 가격이 음수가 아니므로 모든 상품이 대상입니다.
- 최저 가격이 최고 가격보다 큰 경우 검색 요청 전 오류를 안내합니다. API에서도 음수·소수·지수 표기·범위 초과·역전 범위를 거절합니다.
- 검색 조건 지우기는 검색어·지역·가격·판매 상태를 초기화합니다. 다른 사용자 프로필에서 들어온 경우 작성자 조건은 유지합니다. 전체 작성자의 장터로 돌아가려면 홈의 장터 링크를 이용합니다.

조건은 주소에 남고 판매 상태 탭, 새로고침, 상세 이동 후 뒤로 가기와 다음 페이지 조회에도 동일하게 전달됩니다. 최신순 20개씩 표시하며 가격순 정렬·전체 결과 개수·추천 검색은 제공하지 않습니다. 가격은 판매자가 입력한 값입니다. 실제 결제·배송·가격 검증 기능을 추가한 것은 아닙니다.

## API·검색 규칙

`GET /api/posts?kind=market&q=릴&min_price=10000&max_price=20000`을 제공합니다. `region`, `trade_status`, `author`, `before`, 본인의 `saved=1` 조건과 조합할 수 있습니다. 검색어 또는 가격 조건을 장터 종류 없이, 혹은 조황·커뮤니티 종류에 전달하면 오류로 처리합니다. 빈 검색 조건은 기존 목록과 같습니다.

검색어는 SQL 매개변수로 전달하고 `%`, `_`, 역슬래시는 문자 그대로 검색합니다. 검색어가 상품명 또는 설명에 해당하는 OR 조건을 괄호로 묶어 기존 숨김·차단·이용 제한과 AND로 결합합니다. 다른 게시판 글이나 개인 저장 정보가 검색으로 노출되지 않도록 기존 권한을 재사용합니다. 범위를 바꿔도 다음 페이지에서는 같은 조건을 유지합니다.

DB 구조는 스키마 11을 유지하고 기존 글·가격·계정 데이터를 수정하지 않습니다. 추가 검색 인덱스·외부 검색 서비스·외부 전송·캐시 저장은 도입하지 않았습니다. 대규모 자료의 전문 검색 성능 최적화는 후속 검토 사항입니다.

## 검증

자동 검사 총 47개 통과. 상품명·설명 매칭, SQL 와일드카드·역슬래시·삽입 구문을 문자로 취급, 최저/최고 경계 포함과 나눔, 가격 검증, 지역·상태·작성자 조합, 다른 글 종류 제외, 본인 저장 목록·차단 연동, 20개 페이지 경계와 URL 인코딩을 확인했습니다.

로컬 브라우저에서 기존 개발 검증 상품 글을 상품명 ‘장터 상품’·지역 강릉·가격 15,000~15,000원으로 찾았습니다. 거래 완료 탭과 새로고침에서 조건 유지, 최저 16,000/최고 15,000원 오류 안내, 수정 후 재검색을 확인했습니다. 모바일 320·390px 폭에서 가로 넘침이 없음을 확인했습니다. 검증 중 실제 판매 글이나 새 계정을 만들거나 기존 글을 변경하지 않았습니다. 실제 아이폰의 키보드·터치 조작은 아직 별도 확인이 필요합니다.
