# 조황·커뮤니티 제목·본문 검색 — 0.20.0

조황 검색과 커뮤니티에 제목·본문 검색을 추가했습니다. 기존 확정 로고·색상과 글 카드, 작성자 권한·공개 범위를 그대로 재사용합니다. 새로운 외부 검색 서비스나 사용자 자료를 만들지 않았습니다.

## 조황 검색

제목·본문 검색어와 기존 어종·지역·낚시 방식·출조 시작일/종료일을 함께 적용합니다. 제목 또는 본문에 검색어 전체가 포함되고 나머지 입력 조건도 모두 맞는 조황만 표시합니다. 검색어는 앞뒤 공백을 제외한 최대 80자이며 빈 값은 검색어 제한 없음입니다. 여러 단어 분리·유사어·오타 교정 기능은 없습니다.

전체 보기를 누르면 검색어와 기존 검색 조건을 함께 초기화합니다. 선택 조건은 주소에 보관하며 새로고침·상세 진입 후 브라우저 뒤로 가기·추가 페이지 조회에 유지합니다. 조황 검색에 커뮤니티·장터 글을 섞지 않습니다.

## 커뮤니티 검색

커뮤니티의 제목·본문 검색은 사진 없이 등록한 글도 찾습니다. 프로필에서 특정 작성자의 커뮤니티로 이동한 경우 해당 작성자의 글 안에서 검색합니다. 전체 이야기 탭은 검색어를 유지하면서 작성자 조건을 해제하고, 로그인 후 내 글 탭은 같은 검색어로 본인의 글만 표시합니다.

검색어 지우기는 검색어만 지우고 작성자 조건을 유지합니다. 검색 결과가 없으면 조건에 맞는 이야기가 없다는 안내와 전체 이야기 보기를 제공합니다. 목록은 기존 ID 역순으로 20개씩 더 불러옵니다. 상세 화면의 고정 커뮤니티 링크는 전체 목록으로 연결하며, 검색 조건으로 돌아가려면 브라우저 뒤로 가기를 사용합니다.

## API·공개 범위

`GET /api/posts?q=검색어`는 기본 조황 종류에서 검색합니다. `kind=catch`, `kind=community`, `kind=market`으로 특정 게시판을 지정할 수 있습니다. 제목 또는 본문의 LIKE 조건을 괄호로 묶고 다른 조건과 AND로 결합합니다. `%`, `_`, 역슬래시는 SQL 와일드카드 대신 문자로 취급하며 매개변수를 바인딩합니다.

검색어를 기존 지역·어종·방식·출조일·작성자·팔로잉·본인 저장 목록과 결합할 수 있습니다. 단, 화면은 각 게시판에서 의미 있는 조건만 제공합니다. API의 `saved=1`에 종류를 지정하지 않으면 본인에게 보이는 저장 글 종류 전체에서 검색하며 비로그인 접근은 거부합니다. 가격 범위와 거래 상태는 장터 조회에만 허용합니다.

숨김 글·이용 제한된 작성자·현재 계정과 양방향 차단 관계인 작성자의 글은 제외합니다. 검색으로 사진 접근이나 개인 저장 목록 권한을 우회할 수 없습니다. 스키마는 11을 유지하고 기존 계정·사진·글·가격·알림 자료를 변경하지 않았습니다.

## 검증

자동 검사 51개 통과. 제목·본문 매칭, 글 종류 분리, 검색어 특수문자와 길이, 공백 입력, 기존 검색 조건 조합, 개인 저장·팔로잉, 숨김·차단·이용 제한, 커뮤니티 페이지 경계를 확인했습니다.

Chrome 화면 검사 5개 통과. 새 검사에서 작성자 범위 유지·전체 작성자 전환 시 검색어 유지·상세와 뒤로 가기·결과 없음·검색 초기화, 조황 어종/지역/방식/출조 기간 조합과 320·390px 가로 넘침 없음을 확인했습니다. 자동 화면 검사 자료는 별도 임시 DB에만 생성하며 실제 사용자 자료를 바꾸지 않습니다.

추가로 실제 로컬 앱의 기존 개발 검증 글에서 ‘사진’+여수+루어+2026-11-17~2026-11-18 조황 검색 1건과 작성자 2의 ‘커뮤니티 글쓰기 확인’ 검색 1건을 확인하고 화면을 저장했습니다. 이 확인 중 기존 글·사진·계정은 변경하지 않았습니다. 실제 아이폰 Safari의 키보드·터치 조작은 별도 확인이 필요합니다.
