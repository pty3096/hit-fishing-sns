# 낚시용품 장터 — 0.15.0

홈의 낚시용품 장터, PC 왼쪽 장터 메뉴, 프로필의 장터 탭에서 상품 게시판으로 이동합니다. 로그인하지 않아도 공개 상품 글을 볼 수 있습니다. 이메일 인증을 마친 정상 계정이 글을 등록합니다.

## 이용 범위

- 상품명 60자, 거래 지역(시·군·구) 50자, 상품 설명 2,000자 이내를 입력합니다.
- JPG·PNG·WebP 사진 1~5장을 등록합니다. 장당 최대 10MB이며 기존 사진 변환·위치 정보 제거 규칙을 적용합니다.
- 가격은 0~1,000,000,000원의 정수입니다. 0원은 나눔, 나머지는 쉼표와 원 단위로 표시합니다.
- 작성자만 상품 글과 판매 중/거래 완료 상태를 수정할 수 있습니다. 상태는 다시 변경할 수 있으며 사진을 교체하지 않으면 기존 사진을 유지합니다.
- 전체/판매 중/거래 완료와 지역 부분 검색을 함께 적용합니다. 지역·상태·작성자 조건은 주소에 유지되며 20개씩 더 불러옵니다.
- 댓글·좋아요·개인 저장·앱 안 알림·신고·차단·운영자 숨김을 기존 게시물 규칙에 연결합니다. 숨김·차단·이용 제한 글은 목록과 사진 접근에서도 제외합니다.

현재는 상품을 소개하는 게시판입니다. 앱 내 결제·에스크로·배송·주문·개인 채팅·거래 보증은 제공하지 않습니다. 거래 상태는 작성자의 표시이며 실제 거래 성사를 검증하지 않습니다. 개인 연락처를 글에 게시하지 말라는 안내를 제공합니다. 기존 확정 시안의 로고·색상 체계를 사용하며 장터 상세 배치는 이번 구현입니다. 크리에이터 전용 기능은 추가하지 않았습니다.

신규 상품 글의 텍스트 임시 저장 키는 `new-market`으로 조황·커뮤니티와 분리합니다. 사진은 임시 저장하지 않습니다. 등록 요청 재시도 시 중복 방지 규칙을 적용합니다. 조황 피드와 조황 랭킹에 상품 글을 섞지 않으며 개인 저장 목록에는 세 종류의 글을 함께 표시합니다.

## API·데이터

`GET /api/posts?kind=market`에 선택적으로 `trade_status=selling|sold`, `region`, `author`, `before`를 전달합니다. 상태 필터는 장터 조회에만 허용합니다. 기본 글 목록은 기존 조황 목록을 유지합니다.

`POST /api/posts`는 `kind: "market"`, `title`, `region`, 숫자형 `price`, `trade_status`, `body`, `photos`를 받습니다. 상태를 생략하면 판매 중입니다. `PATCH /api/posts/:id`는 기존 글 종류를 바꿀 수 없고 작성자만 접근합니다. 수정 시 사진·거래 상태 생략은 기존 값을 유지하며 가격 등 필수 필드는 재입력합니다. 가격 문자열·소수·음수·범위 초과는 거절합니다.

스키마 버전 11에서 기존 posts에 nullable `price`, `trade_status`를 추가합니다. 기존 조황·커뮤니티 행과 계정 자료를 보존합니다. 개발 DB와 별도 휴대폰 시범 DB를 각각 백업하고 무결성을 확인한 뒤 적용했습니다. DB·사진·메일·백업은 GitHub에 등록하지 않습니다.

## 검증

자동 검사 총 37개 통과. 사진 필수, 가격 범위, 작성 권한, 종류 변경 금지, 상태·지역 필터, 사진 유지, 중복 등록 방지, 재시작 후 유지, 저장·댓글·알림·신고, 숨김·차단·탈퇴 연동, 20개 페이지 경계, 조황 랭킹 제외를 확인했습니다.

로컬 브라우저에서 개발 검증용 상품을 사진 1장·15,000원·강릉으로 등록했습니다. 상품 수정으로 거래 완료를 저장하고 사진 유지, 판매 중 목록에서 제외, 거래 완료 목록과 강릉 검색에서 표시를 확인했습니다. 실제 판매 글이 아닌 개발 검증용 글이라고 명시했습니다. 모바일 320·390px 폭에서 가로 넘침이 없음을 확인했습니다. 실제 아이폰 Safari 조작과 실제 사용자 간 거래는 검증하지 않았습니다.

후속 0.18.0에서 상품명·설명·가격 범위 검색을 추가했습니다. [상품 검색 상세](29_MARKET_SEARCH.md)를 참고해주세요.
