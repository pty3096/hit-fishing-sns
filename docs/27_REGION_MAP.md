# 지역별 낚시지도 — 0.16.0

홈의 낚시지도 또는 PC 왼쪽 낚시지도 메뉴에서 지역 주변 지도와 해당 지역의 조황을 봅니다. 확정 UI v1.1의 공통 로고·색상을 재사용하며 상세 지도 화면은 이번 구현입니다.

## 제공 범위

전국·거제·통영·제주·부산·강릉·여수·인천·태안의 미리 정한 넓은 지도 범위를 제공합니다. 이 범위는 주변을 찾아보기 위한 참고 창이며 행정 경계·낚시 가능 구역을 뜻하지 않습니다. 지도에는 실제 조황 위치 핀을 만들지 않습니다. 특정 어종 출현·출입 허가·현장 안전·운항 조건도 판정하지 않습니다.

지역 선택 시 조황의 기존 지역 문자열을 부분 검색합니다. 조황 목록은 기존 최신순 20개씩 추가 조회하고, 숨김·차단·이용 제한된 작성자에 대한 공개 범위를 그대로 적용합니다. 장터·커뮤니티 글은 제외합니다. 임의의 지역을 직접 입력할 수 있으나 미리 준비한 이름과 정확히 일치하지 않으면 전국 지도와 별도 안내를 표시하고 조황은 입력한 지역으로 검색합니다. 예를 들어 강릉시는 조황 검색에 사용하되 지도 범위는 전국으로 대체합니다.

선택 지역은 `#map?region=...` 주소에 보관해 상세 이동·뒤로 가기·새로고침 시 유지합니다. 이전 `#coming/map` 주소는 새 지도 화면으로 연결합니다. 지도 이동·확대는 외부 임베드 안에서만 동작하며 조황 검색 범위를 자동으로 바꾸지 않습니다. 좌표로 누르는 핀·현재 위치·길찾기·포인트 등록·오프라인 지도는 이번 범위에 포함하지 않습니다.

## 외부 지도

‘외부 지도 불러오기’를 누르기 전에는 iframe을 만들지 않습니다. 누르면 OpenStreetMap의 공식 export/embed.html로 연결하며 지도 이동·확대를 제공합니다. 지도 안의 출처 표기를 유지하고 바깥에도 OpenStreetMap 기여자 저작권 링크를 표시합니다. 외부 지도 서비스에는 IP 등 일반 접속 정보가 전달됩니다. 앱은 로그인 토큰·사용자 계정·사진·조황 내용·임의 검색 문자열을 외부 주소에 넣지 않고 미리 정한 넓은 지도 범위만 전달합니다. GPS 권한을 요청하지 않으며 사진 EXIF 위치 정보 제거 규칙도 유지합니다.

지도가 비어 있거나 차단되면 ‘지도 크게 열기’를 사용할 수 있고, 외부 지도 없이도 앱의 지역 검색·조황 목록은 이용할 수 있습니다. iframe 로드 이벤트만으로 지도 연결 성공이라고 안내하지 않습니다. 지도 서비스의 가용성은 보장하지 않습니다. 외부 링크는 새 탭에서 열며 opener와 referrer를 전달하지 않습니다.

[OpenStreetMap 공식 내보내기 문서](https://wiki.openstreetmap.org/wiki/Export_tab)의 iframe 방식을 사용합니다. [출처 표시 지침](https://osmfoundation.org/wiki/Attribution_Guidelines)과 [타일 이용 정책](https://operations.osmfoundation.org/policies/tiles/)을 참고했습니다. 별도 타일 다운로드·오프라인 저장·사전 수집을 구현하지 않았으며, 공개 서비스 규모로 확장하기 전 지도 제공 방식과 이용 정책을 다시 확인해야 합니다.

## 데이터·보안

새 데이터베이스 테이블이나 좌표 필드는 추가하지 않습니다. 기존 조황 지역과 `GET /api/posts?region=...`을 재사용하며 스키마는 11입니다. 정밀 좌표를 수집하지 않는 기존 설계 범위를 유지합니다. 개발·별도 휴대폰 시범 DB의 기존 계정과 게시물을 보존합니다.

`public/region-map.mjs`는 화면 표시 범위와 주소 생성만 담당합니다. 임의 검색어를 지도 주소·도메인으로 사용하지 않습니다. 앱 CSP는 외부 frame 출처를 `https://www.openstreetmap.org` 하나로 제한하고 스크립트는 기존대로 self만 허용합니다. iframe은 sandbox를 적용하고 geolocation을 허용하지 않습니다. 외부 지도에 앱의 DOM·세션을 전달하지 않습니다.

## 검증

자동 검사 총 40개 통과. 고정 지도 범위·외부 주소 생성·임의 검색어가 외부 URL에 포함되지 않음·URL 인코딩·검색 길이 제한·지도 모듈 제공·CSP 제한과 기존 회귀 검사를 확인했습니다. 로컬 접속 검사에도 신규 모듈을 포함했습니다.

로컬 브라우저에서 불러오기 전 iframe 없음, 강릉 선택 후 실제 OpenStreetMap 배경 지도와 확대/축소 컨트롤 표시, 해당 지역 조황 목록, 울릉 검색 시 전국 지도 안내와 빈 목록을 확인했습니다. 모바일 320·390px 폭에서 가로 넘침이 없음을 확인했습니다. 실제 아이폰 Safari의 터치 조작은 아직 별도 확인이 필요합니다. 지도 열람 외 계정·게시물 데이터를 새로 만들거나 변경하지 않았습니다.
