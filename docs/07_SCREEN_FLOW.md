# 첫 버전 화면 설계 · 연결 시연

## 결과물

`prototype/index.html`을 브라우저에서 열면 별도 설치 없이 화면을 확인할 수 있습니다. 모바일·PC 공통 화면을 제공하는 신규 구현안입니다. 기존 확정 UI v1.1 원본의 복원본이 아닙니다. 로고는 원본 확보 전까지 임시 문자로 표시합니다.

## 연결 흐름

- 홈 → 조황 상세 → 시연 로그인 → 좋아요·댓글·팔로우
- 홈 → 작성 → 시연 로그인 → 사진·조황 입력 → 등록된 상세 → 프로필
- 검색 → 어종·지역 필터 → 결과 또는 결과 없음 → 상세
- 프로필 → 내 게시물 또는 첫 기록 안내 → 작성
- 프로필 → 시연 로그아웃 → 홈

PC는 왼쪽 메뉴·중앙 피드·오른쪽 안내, 모바일은 단일 피드·하단 메뉴를 사용합니다.

## 시연 범위

샘플 조황 2개, 빈 팔로잉·프로필 상태, 검색 결과 없음, 이미지 선택·미리보기, 작성 후 피드·프로필 연결, 로그인 유도, 좋아요·댓글·팔로우를 메모리에서 시연합니다. 사진은 서버로 보내지 않습니다. 새로고침하면 모든 입력과 시연 계정 상태가 초기화됩니다.

사진 제한은 화면 검증을 위한 임시 기준(JPG·PNG·WebP, 장당 10MB, 1~5장)입니다. 카드에는 선택한 첫 사진을 표시하며 다중 사진 열람은 후속 구현 대상입니다.

## 다음 개발 단계

실제 가입·인증, 데이터 저장, 작성자 권한 검사, 이미지 검증·메타데이터 제거, 수정·삭제, 프로필 편집, 신고·차단·운영 화면, 탈퇴는 아직 구현하지 않았습니다. 현재 시연 로그인은 인증이 아닙니다. 실제 비밀번호를 입력받지 않습니다.

다음 단계에서는 기술 스택과 데이터·권한 모델을 선정하고 실제 계정으로 조황을 저장하는 흐름부터 구현합니다.

## 현재 구현 보완

위 초기 흐름은 최초 시연 기준입니다. 현재 실제 앱은 다중 사진 갤러리·사진 검증·영구 저장·인증·소통·운영 기능을 제공합니다. [현재 준비 상태](37_RELEASE_READINESS.md)를 참고해주세요.
