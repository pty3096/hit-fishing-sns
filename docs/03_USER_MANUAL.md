# 사용자 매뉴얼 — 원본 대기

상태: 기능 안내 범위만 복구. 실제 서비스 사용 절차는 검증하지 못했습니다.

이전 대화에서 회원가입, 게시물·영상 업로드, 팔로우, 포인트 검색, 출조 예약을 안내 대상으로 열거했습니다. 화면별 버튼, 입력 조건, 오류 처리, 계정 삭제 등 상세 절차는 미확보입니다.

| 예정 안내 | 현재 확인 범위 |
| --- | --- |
| 회원가입·로그인 | 구체적인 인증 방식 미확인 |
| 게시물·영상 업로드 | 형식·용량·공개 범위 미확인 |
| 팔로우 | 상세 동작 미확인 |
| 포인트 검색 | 검색·지도 동작 미확인 |
| 출조 예약 | 신청·결제·취소 절차 미확인 |

복구한 모바일 홈 참고 이미지에는 조황피드, 숏폼영상, 낚시지도, 출조예약, 커뮤니티, 랭킹 메뉴가 보입니다. 이는 시각 자료의 표기이며 실제 구현된 기능이나 최종 메뉴 구성의 증거는 아닙니다.

서비스 주소와 구현본이 없어 사용자 흐름 검증을 수행하지 못했습니다. 실제 화면 확보 후 단계별 사용법과 오류 대응을 작성해야 합니다.

출처와 한계: [SOURCE_STATUS.md](SOURCE_STATUS.md).


## 후속 구현: 내 글 관리

0.21.0부터 내 프로필의 내 글 관리에서 조황·커뮤니티·장터를 나눠 검색하고 수정할 수 있습니다. 로그인·이메일 인증이 필요합니다. [상세 사용 안내](33_MY_POSTS.md)를 참고해주세요.

## 후속 구현: 댓글 수정

0.22.0부터 본인 댓글의 댓글 수정 버튼에서 300자 이내로 내용을 고치고 저장하거나 취소할 수 있습니다. 댓글 편집은 임시 저장되지 않습니다. [댓글 수정·재시도 안내](34_COMMENT_EDIT.md)를 참고해주세요.

## 후속 구현: 공유 링크

0.23.0부터 글 상세와 조황·커뮤니티·장터 검색의 링크 복사 버튼으로 현재 글이나 적용된 검색 조건의 주소를 복사합니다. 자동 복사가 막히면 표시된 링크를 직접 선택해 복사할 수 있습니다. [공유 링크 안내](35_SHARE_LINKS.md)를 참고해주세요.

## 후속 구현: 가입·인증 후 이어서 진행

0.24.0부터 같은 탭에서 로그인·가입·인증을 마치면 열려던 작업으로 돌아갑니다. 복귀 정보는 최대 30분 유지합니다. [사용 방법과 제한](36_ONBOARDING_RESUME.md)을 참고해주세요.

0.26.0부터 프로필 사진을 고른 뒤 사진 선택 취소로 기존 사진으로 돌아갈 수 있습니다. 잘못된 파일을 고르면 대기 사진을 비우므로 다시 선택해주세요. 저장 실패 시에는 같은 화면에서 다시 저장할 수 있습니다. [프로필 사진 안내](13_PROFILE_PHOTO.md)를 참고해주세요.
