# 연결 대기 제한·시범 진단 — 0.30.0

## 앱 동작

조회 요청은 15초, 변경·저장 요청은 90초 뒤에도 응답이 끝나지 않으면 중단하고 안내합니다. 응답 본문을 읽는 시간도 포함합니다. 조회는 연결 확인과 다시 시도를 안내하고, 저장은 결과를 확인하지 못했으니 반영 여부부터 확인하도록 안내합니다. 중단은 서버에서 처리가 취소됐음을 뜻하지 않습니다. 저장·가입·댓글 등의 요청을 자동으로 다시 보내지 않습니다. 기존 글·댓글의 재시도 식별자와 소유자 검사는 유지합니다.

연결 실패, 응답 대기 초과, JSON이 아닌 응답, 서버에서 명시한 권한·입력 오류를 구분합니다. 외부 리다이렉트를 자동으로 따라가지 않습니다. 시범 화면의 접속 다시 확인 버튼은 사용자가 누를 때만 전체 페이지를 새로 엽니다. 토큰·로그인 쿠키를 읽거나 저장하지 않습니다.

## 읽기 전용 시범 진단

```sh
npm run check:preview -- https://발급주소.trycloudflare.com
```

정확한 HTTPS origin만 허용합니다. 로컬 3002 시범 서버에서 상태·시범 설정·비로그인 상태·메일함 제한·공개 글 목록·연결 처리 파일을 확인합니다. 외부 주소에서는 쿠키 없이 /api/health를 요청하고 Cloudflare의 HTTPS 로그인 주소로 이동하는 응답인지 확인합니다. 로그인 주소를 따라가지 않고 인증번호를 발송하거나 입력하지 않습니다. 결과에는 상태 매개변수·인증정보·목록 내용·사용자 정보를 출력하지 않습니다.

외부 API가 인증 없이 직접 정상 응답하거나 엉뚱한 호스트로 이동하면 보호 확인이 필요한 것으로 표시합니다. 이 검사는 서버·외부 진입점만 검사하며 사용자의 아이폰 세션·실제 메일 수신·Safari 동작을 확인하지 않습니다. 시범 주소는 기록이나 저장소에 하드코딩하지 않습니다. 로컬 프로세스와 터널이 실행 중이어야 합니다.

## 확인 기록

기본 검사 63개·Chrome 화면 검사 16개·로컬 연결 점검이 통과했습니다. 실제 실행 중인 별도 시범 서버와 보호 연결에 대한 진단 7개도 통과했습니다. 임시 대체 요청으로 대기 초과·본문 읽기 지연·자동 재전송 없음·타이머 정리·잘못된 응답·보호 확인 실패를 검증했습니다. 기존 개발·휴대폰 기록을 변경하지 않았습니다. 사용자 아이폰에서 제보한 오류 원인과 복구 성공은 아직 확정하지 않습니다.
