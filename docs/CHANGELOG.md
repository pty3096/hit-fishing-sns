# 변경 이력

## 아이폰 보호 시범 접속

- 이메일 인증으로 보호된 임시 주소와 별도 시범 DB 연결.
- 외부 요청 주소 검증·Secure 쿠키·아이폰용 인증 링크 변환.
- 자동 검사 25개 통과, 실기기 조작 결과는 확인 대기.

## 0.7.1 — 휴대폰 시범 사용 준비

- 실행 중인 로컬 앱을 읽기 전용으로 확인하는 `check:local` 추가, 10개 항목 통과.
- 실제 휴대폰 점검표·기대 결과·실패 기록 양식 추가. 실기기 검증은 미실행으로 표시.
- 휴대폰에서 PC 루프백 주소로 접속할 수 없는 현재 제약 명시.

## 0.7.0 — 작성 중 글 보호

- 계정·신규 글·수정 글별 텍스트 임시 저장과 이어쓰기.
- 이 탭에서 24시간 보관, 사진 제외 안내, 이동·새로고침 전 확인.
- 로그아웃·탈퇴·등록 성공 시 정리, 저장 공간 오류 안내.
- 자동 검사 23개 통과, 브라우저에서 이동 취소·이어쓰기 확인.

## 0.6.0 — 사용성 점검

- 부분 지역·어종 검색, 검색 조건의 뒤로 가기·새로고침 유지.
- 검색·팔로잉·프로필별 빈 목록 안내와 입력 전 로그인·인증 안내.
- 사진 이동 버튼·방향키·현재 번호, 키보드 본문 이동·초점 개선.
- 모바일 글자·버튼·줄바꿈·보조 글자 대비 개선.
- 연결 오류 안내·재시도와 페이지 추가 로딩 실패 후 재시도 개선.
- 320·390·1440px 브라우저 점검, 자동 검사 21개 통과.

## 0.5.0 — 프로필 사진

- 본인 프로필 사진 업로드·미리보기·교체·기본 이미지 복원.
- 서버 검증·메타데이터 제거·512×512 WebP 저장.
- 프로필·조황 피드·댓글·팔로워 목록에 현재 사진 반영.
- 차단·이용 제한·탈퇴와 사진 접근·삭제 연동, 운영자 사진 검토.
- 스키마 5 추가, 기존 자료 백업·보존, 자동 검사 17개 통과.

## 0.4.0 — 이메일 인증·재설정·배포 준비

- 인증·재설정용 만료·일회용 토큰과 계정별 개발 메일함.
- 인증 전 작성·소통 제한, 재설정 후 기존 비밀번호·세션 무효화.
- SMTP 연결 설정과 운영 모드의 개발 메일 차단.
- Docker·Caddy·Compose, GitHub 검증 작업, 상태 확인 API.
- 데이터베이스 백업·무결성 검사와 복원 테스트.
- 기존 데이터 보존, 자동 검사 14개 통과; 실제 SMTP·공개 배포는 미실행.

- 기존 데이터 백업, 자동 검사 8개 통과 및 브라우저 신고·차단·운영 검증.
