## 사진 선택 안내 보완 — 0.7.2

HEIC·HEIF 원본은 직접 업로드할 수 없습니다. JPG로 변환하거나 PNG 스크린샷을 선택해주세요. 파일 확장자만 바꾸는 것은 변환이 아닙니다. 새 사진을 JPEG로 촬영하는 설정은 [Apple 안내](https://support.apple.com/en-gb/116944)를 참고해주세요. 이미 촬영한 사진은 별도 변환이 필요합니다.

사진 선택 오류는 입력란 아래에 계속 표시되며 정상 재선택 시 해제됩니다. 잘못된 선택 묶음은 추가하지 않고 기존 사진과 글을 유지합니다. 선택 장수도 표시합니다. 프로필 사진에도 같은 형식·용량 안내를 적용했습니다. 서버는 실제 파일을 해독해 검증합니다.

PC 브라우저에서 PNG 선택 → HEIC 테스트 파일 선택 → 오류와 기존 사진 1장·제목 보존 → PNG 재선택 → 오류 해제·사진 2장 표시를 확인했습니다. 실제 아이폰의 사진 선택·자동 변환은 사용자 확인 대기입니다. 자동 검사 26개 통과.
