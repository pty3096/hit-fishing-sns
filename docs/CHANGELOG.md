# 변경 이력

## 0.4.0 — 이메일 인증·재설정·배포 준비

- 인증·재설정용 만료·일회용 토큰과 계정별 개발 메일함.
- 인증 전 작성·소통 제한, 재설정 후 기존 비밀번호·세션 무효화.
- SMTP 연결 설정과 운영 모드의 개발 메일 차단.
- Docker·Caddy·Compose, GitHub 검증 작업, 상태 확인 API.
- 데이터베이스 백업·무결성 검사와 복원 테스트.
- 기존 데이터 보존, 자동 검사 14개 통과; 실제 SMTP·공개 배포는 미실행.

## 0.3.0 — 신고·운영·탈퇴

- 게시물·댓글·사용자 신고 및 중복·빈도 제한.
- 차단·해제와 양방향 콘텐츠·상호작용 제한.
- 운영자 권한 분리, 신고 검토·숨김·복원·이용 제한·해제 및 이력.
- 비밀번호 확인 후 회원 탈퇴와 연관 데이터 삭제.
- 스키마 3 추가 및 삭제한 계정·게시물 번호 재사용 방지.
- 기존 데이터 백업, 자동 검사 8개 통과 및 브라우저 신고·차단·운영 검증.

## 0.2.0 — 사진·소통

- 실제 사진 업로드·메타데이터 제거·갤러리·사진 편집 연결.
- 댓글 작성·본인 댓글 삭제, 좋아요·취소, 팔로우·취소 연결.
- 공개 프로필·팔로워·팔로잉 목록·팔로잉 피드 추가.
- 기존 데이터 백업 후 스키마 2로 테이블 추가.
- 이미지·권한·데이터 유지 자동 검사와 브라우저 흐름 검증.
