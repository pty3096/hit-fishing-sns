# 이메일 인증·비밀번호 재설정

## 로컬에서 확인

1. `npm start`로 앱을 실행합니다.
2. 회원가입 후 내 프로필 → 설정 → 개발용 메일함을 엽니다.
3. 인증 안내를 열고 이메일 인증 완료하기를 누릅니다.
4. 설정에서 인증 완료 상태를 확인합니다. 글 작성·댓글·좋아요·팔로우 등은 인증 후 이용할 수 있습니다.

기존 개발 계정도 이메일 인증이 필요합니다. 데이터와 비밀번호는 보존했으며, 기존 이메일을 실제 소유한다고 추정해 인증 처리하지 않았습니다. 기존 계정에서는 설정 → 인증 안내 다시 받기를 사용합니다.

현재 `MAIL_MODE=local`입니다. 실제 이메일을 보내지 않고 개발 데이터베이스의 본인 메일함에 안내를 저장합니다. 다른 계정의 안내는 웹에서 볼 수 없습니다. 운영 모드나 외부 도메인에서는 개발용 메일함을 사용할 수 없습니다.

## 비밀번호 재설정

로그인 화면의 비밀번호를 잊으셨나요 또는 설정의 재설정 안내 받기를 선택하고 가입한 이메일을 입력합니다. 계정 존재 여부를 노출하지 않도록 동일한 안내를 표시합니다.

로컬에서 로그인할 수 없는 경우 이 PC의 프로젝트 터미널에서 다음을 사용합니다.

```sh
npm run mailbox -- list
npm run mailbox -- show 1
```

`1`은 실제 메일 번호로 바꿉니다. 안내 링크는 계정에 접근할 수 있는 비밀 정보이므로 공유하지 않습니다. 실제 운영에서는 사용자가 본인의 이메일에서 안내를 받습니다.

새 비밀번호는 12~128자로 두 번 입력합니다. 변경하면 기존 기기의 로그인 세션을 모두 폐기하고 다시 로그인하도록 안내합니다. 이메일 소유를 확인한 재설정은 이메일 인증도 완료하지만 계정의 운영자 권한이나 이용 제한 상태를 변경하지 않습니다.

## 링크 처리

- 이메일 인증: 24시간, 비밀번호 재설정: 30분 유효
- 새 링크를 요청하면 같은 용도의 이전 링크 무효화
- 한 번 사용한 링크 재사용 금지, 동시 요청도 한 번만 적용
- 운영용 토큰은 데이터베이스에 해시만 저장
- 비밀번호 재설정 시 모든 인증·재설정 토큰과 기존 세션 폐기
- 토큰은 URL의 fragment에 포함해 일반 HTTP 요청 경로에 실리지 않게 처리
- 사용 완료 후 화면 주소에서 토큰 제거, Referrer-Policy는 no-referrer
- 재발송·재설정·링크 검증에 요청 제한 적용

개발용 메일함에는 동작 확인을 위해 원문 링크를 저장합니다. 사용하거나 만료된 링크는 표시하지 않습니다. 계정 탈퇴 시 토큰과 개발 메일도 함께 삭제합니다.

## 실제 이메일 발송 연결

SMTP를 지원하는 서비스에 다음 설정을 제공하면 같은 기능을 실제 메일로 보낼 수 있습니다. 현재는 외부 서비스나 발신 도메인을 만들지 않았습니다.

| 설정 | 의미 |
| --- | --- |
| MAIL_MODE=smtp | 실제 발송 모드 |
| SMTP_HOST, SMTP_PORT | 발송 서버·포트 (기본 587) |
| SMTP_USER, SMTP_PASS | 서비스에서 발급한 발송 자격 정보 |
| MAIL_FROM | 서비스에서 허용한 발신 주소 |
| APP_ORIGIN | 안내 링크에 사용할 사이트 주소 |

465는 TLS로 직접 연결하고 다른 포트는 STARTTLS를 요구합니다. 인증서 검증을 끄는 옵션은 제공하지 않습니다. 외부 서비스가 허용한 발신 주소와 도메인을 연결하고 실제 수신·스팸 처리·실패 대응을 확인해야 합니다. SMTP 실패 시 서버에는 링크나 자격 정보를 출력하지 않고 발송 실패만 기록합니다. 실패한 발송을 자동 재시도하는 작업 큐는 아직 없습니다.

## 검증 범위

자동 테스트에서 인증 전 작성 차단, 메일함 접근 분리, 토큰 만료·재발송·재사용·동시 사용, 재설정 후 이전 비밀번호·세션 거부, 운영 모드 메일함 비활성화, 백업 복원을 확인했습니다. SMTP 테스트는 외부로 보내지 않는 대체 발송 함수로 확인했습니다. 실제 SMTP 송수신 성공을 의미하지 않습니다.

브라우저에서 개발 계정의 인증 완료와 재설정 안내·새 비밀번호 입력 화면을 확인했습니다. 실제 계정의 비밀번호는 변경하지 않았습니다.

구현 참고: [Nodemailer SMTP](https://nodemailer.com/smtp), [OWASP 비밀번호 재설정 지침](https://cheatsheetseries.owasp.org/cheatsheets/Forgot_Password_Cheat_Sheet.html).
