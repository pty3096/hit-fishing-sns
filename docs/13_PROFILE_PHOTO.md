# 프로필 사진

## 사용 방법

내 프로필 → 프로필 편집에서 사진을 선택하고 사진 저장을 누릅니다. 사진은 닉네임·소개와 별도로 저장합니다. 기본 이미지로 변경을 누르면 등록한 프로필 사진을 삭제하고 기본 아이콘을 사용합니다.

선택한 사진을 미리보기로 확인할 수 있습니다. JPG·PNG·WebP 사진 한 장, 최대 10MB를 지원합니다. 움직이는 이미지·동영상·HEIC는 지원하지 않습니다. 가로 사진이나 세로 사진은 가운데를 기준으로 정사각형에 맞추며, 현재는 자르기 위치를 직접 조절하는 편집기는 없습니다.

## 저장과 표시

- 서버에서 실제 이미지 디코딩·형식·크기를 검사합니다.
- 방향을 보정하고 512×512 WebP로 변환하며 원본 위치 정보를 포함한 메타데이터를 제거합니다.
- 원본 파일명·원본 사진은 보관하지 않습니다.
- 프로필, 조황 피드, 댓글, 팔로워·팔로잉 목록에서 현재 사진을 표시합니다.
- 사진을 바꾸거나 삭제하면 이전 이미지 주소는 사용할 수 없습니다.
- 잘못된 사진을 보내면 기존 사진을 보존합니다.

사진은 SQLite의 `avatars` 테이블에 저장되며 스키마 버전은 5입니다. 다른 계정·글·사진을 지우지 않고 테이블을 추가했습니다. 계정 탈퇴 시 해당 프로필 사진도 삭제합니다.

## 권한과 운영

이메일 인증한 본인만 자기 사진을 변경·삭제할 수 있습니다. 요청에 다른 계정 번호를 넣어도 그 계정의 사진을 바꾸지 않습니다.

차단 관계나 이용 제한 상태는 프로필 사진 직접 조회에도 적용합니다. 공개 사진이므로 로그아웃 상태에서는 차단 관계와 무관하게 볼 수 있습니다. 운영자는 사용자 신고 상세에서 현재 프로필 사진을 검토할 수 있으며, 이용 제한된 계정 사진도 운영자 전용 주소에서만 볼 수 있습니다.

프로필 사진 변경 이력을 별도로 남기지는 않습니다. 사용자가 바꾼 이전 사진을 운영자가 소급해서 조회하는 기능은 없습니다.

## API

| 요청 | 기능 |
| --- | --- |
| PUT /api/profile/photo | 본인 프로필 사진 저장·교체; `photo: {data: base64}` |
| DELETE /api/profile/photo | 본인 사진 삭제·기본 아이콘으로 변경 |
| GET /api/avatars/:userId/:revision | 현재 공개 프로필 사진 |
| GET /api/admin/avatars/:userId/:revision | 신고 검토용 운영자 전용 사진 |

계정·조황·댓글·팔로우 목록 API 응답의 `avatar_url`에 현재 사진 경로를 제공합니다. 사진이 없으면 null입니다. 사진 파일과 개발 검증 자료는 `data/`에 저장하며 GitHub에 올리지 않습니다.

## 검증

자동 검사에 사진 정규화·메타데이터 제거, 프로필·피드·댓글·목록 반영, 인증과 작성자 구분, 실패 시 기존 사진 보존, 이전 주소 무효화, 차단·이용 제한·운영 권한, 서버 재시작 후 유지, 탈퇴 시 삭제를 추가했습니다. 기존 검사와 합쳐 17개가 통과했습니다.

브라우저에서 개발 검증 계정에 검증용 이미지를 선택하고 저장한 뒤 프로필과 새로고침 후 유지 상태를 확인했습니다. 실제 사용자 사진을 임의로 변경하지 않았습니다.

## 0.26.0 선택 취소·실패 복구

사진을 선택하면 ‘사진 저장을 눌러야 반영됩니다’라는 상태와 사진 선택 취소 버튼을 표시합니다. 취소하면 저장된 프로필 사진(없으면 기본 아이콘)으로 돌아갑니다. 잘못된 형식·빈 파일·용량 초과 등 선택 검증 오류가 나면 이전 저장 대기 사진도 비우고 다시 선택하도록 합니다. 이전에 선택한 사진을 잘못 저장하지 않도록 하기 위한 동작입니다. 저장된 사진은 이 과정에서 삭제하지 않습니다.

저장 중에는 사진 선택·선택 취소·기본 이미지 변경을 잠급니다. 저장 요청이 실패하면 선택한 사진과 미리보기를 유지하고 다시 저장하거나 취소할 수 있다고 안내합니다. 이 대기 사진은 화면을 나가거나 새로고침하면 사라지며 사진 임시 저장 기능은 아닙니다.

임시 계정·임시 DB의 Chrome에서 선택→취소, 정상 선택 후 HEIC 선택 거부·이전 대기 사진 제거, 통신 실패 후 미리보기 유지·재시도 성공, 저장된 사진이 있을 때 취소 복원, 320·390px 가로 넘침을 확인했습니다. 자동 검사 57개·화면 검사 13개·로컬 연결 점검이 통과했습니다. 실제 아이폰 사진 보관함과 Safari 파일 선택 창은 아직 별도 확인이 필요합니다. HEIC 변환 기능을 추가한 것은 아닙니다. 현재 전체 DB 스키마는 11이며 이번 변경에는 DB 변경이 없습니다.
