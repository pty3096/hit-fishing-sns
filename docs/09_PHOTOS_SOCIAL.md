# 사진·소통 기능

## 이번에 연결한 흐름

- 조황 작성 → 사진 1~5장 선택 → 미리보기·개별 제거 → 저장 → 피드와 상세 갤러리
- 조황 수정 → 기존 사진 유지·제거 및 새 사진 추가 → 글과 사진 함께 저장
- 상세·피드 → 좋아요·취소 → 새로고침 후 상태 유지
- 상세 → 댓글 작성·본인 댓글 삭제
- 작성자 이름 → 공개 프로필 → 팔로우·취소 → 팔로잉 피드
- 프로필 → 팔로워·팔로잉 목록 → 다른 사용자 프로필

## 사진 처리

JPG·PNG·WebP를 장당 10MB, 최대 5장까지 받습니다. 새 조황에는 사진 1장 이상이 필요합니다. 이전 단계에서 작성한 사진 없는 글은 유지하며 사진 없이 글을 수정할 수 있습니다.

서버는 확장자나 브라우저가 보내는 MIME만 신뢰하지 않고 실제 파일을 디코딩합니다. 최대 4천만 픽셀, 단일 프레임만 허용합니다. 방향 보정 후 가로·세로 최대 1920픽셀의 WebP로 변환하고 원본의 EXIF·XMP·IPTC 메타데이터를 저장하지 않습니다. 처리에는 [sharp](https://sharp.pixelplumbing.com/api-output/)를 사용합니다.

사진은 SQLite 내부에 저장됩니다. 원본 파일명과 원본 사진은 보관하지 않습니다. 이미지와 글의 교체는 한 트랜잭션으로 저장하고, 검증 실패 시 기존 글과 사진을 유지합니다. 게시물을 삭제하면 사진·댓글·좋아요도 함께 삭제합니다.

로컬 개발용으로 사진을 JSON의 base64 데이터로 전송합니다. 큰 파일에서는 전송 및 처리에 시간이 걸릴 수 있습니다. 공개 배포 전에는 별도 파일 저장소, 업로드 요청 제한 및 저장 용량 관리가 필요합니다. HEIC와 동영상은 지원하지 않습니다.

## 소통 규칙

- 좋아요·팔로우 추가는 중복 요청에도 하나만 저장합니다.
- 자신의 계정은 팔로우할 수 없습니다.
- 댓글은 1~300자이며 본인이 쓴 댓글만 삭제할 수 있습니다.
- 공개 조회에는 닉네임·소개만 제공하며 이메일은 반환하지 않습니다.
- 댓글·팔로워·팔로잉은 20개 단위로 더 불러올 수 있습니다.
- 댓글은 최신순으로 표시하고 이전 댓글을 추가로 불러옵니다.

## 추가 데이터·API

스키마 버전 2: `photos`, `likes`, `comments`, `follows`를 기존 테이블에 추가합니다. 기존 계정·세션·조황을 삭제하지 않습니다. 실제 로컬 데이터베이스는 업그레이드 전에 `data/backups/`에 백업했습니다.

| 요청 | 기능 |
| --- | --- |
| GET /api/photos/:id | 변환된 사진 조회 |
| PUT, DELETE /api/posts/:id/like | 좋아요·취소 |
| GET, POST /api/posts/:id/comments | 댓글 목록·작성 |
| DELETE /api/comments/:id | 본인 댓글 삭제 |
| GET /api/users/:id | 공개 프로필·팔로우 수·내 팔로우 상태 |
| PUT, DELETE /api/users/:id/follow | 팔로우·취소 |
| GET /api/users/:id/followers, /following | 팔로워·팔로잉 목록 |
| GET /api/posts?following=1 | 팔로잉 최신순 피드 |
| GET /api/posts?author=:id | 작성자별 조황 |

사진 입력은 게시물 저장 시 `photos: [{data: base64}]`로 전달합니다. 수정할 때 현재 게시물의 사진은 `{id: 기존사진ID}`로 유지할 수 있습니다. 타인의 사진 ID를 붙여 넣는 요청은 거부합니다. `photos` 필드를 생략하면 기존 사진을 유지합니다.

## 검증과 남은 작업

자동 테스트: 사진 디코딩·방향 보정·메타데이터 제거, 잘못된 사진·초과 장수·다른 게시물 사진 거부, 실패 시 기존 데이터 유지, 이미지 삭제 연동, 두 계정 간 댓글 삭제 권한, 중복 좋아요·팔로우, 서버 재시작 후 사진·소통 데이터 유지, 팔로잉 피드 및 취소를 확인했습니다.

실제 브라우저: 검증용 이미지 첨부 → 조황 저장 → 좋아요·댓글 → 새로고침 후 유지, 두 번째 검증 계정에서 작성자 팔로우 → 팔로잉 피드 표시를 확인했습니다. 검증 이미지와 글은 실제 조황으로 오해하지 않도록 표시했습니다.

신고·차단·운영자 관리·탈퇴, 이메일 인증·비밀번호 재설정, 공개 배포는 아직 미구현입니다.
