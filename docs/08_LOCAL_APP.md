# 실제 계정·조황 저장 기반

이 문서는 최초 계정·글 저장 단계의 기록입니다. 현재 사진·소통 기능과 추가 API는 [후속 개발 문서](09_PHOTOS_SOCIAL.md)를 함께 확인해주세요.

## 실행

Node.js 24가 필요합니다. 사진 처리 패키지를 설치해야 하며 별도 데이터베이스 설치는 필요하지 않습니다.

```sh
npm ci
npm start
```

브라우저에서 http://127.0.0.1:3000 으로 접속합니다. 종료는 실행 중인 터미널에서 Ctrl+C입니다. 포트 변경은 `PORT=3001 npm start`로 가능합니다. 쿠키와 요청 출처 확인을 위해 표시된 127.0.0.1 주소를 사용합니다.

## 이번 단계에서 가능한 기능

- 이메일·닉네임·비밀번호 회원가입, 로그인·로그아웃
- 비밀번호 12~128자, 개별 salt와 scrypt 해시 저장
- HttpOnly·SameSite 쿠키, 서버에는 세션 토큰의 해시 저장, 7일 만료
- 글 조황 작성·조회·본인 게시물 수정·삭제
- 어종·지역 정확히 일치 검색, 20개 단위 목록
- 내 게시물, 닉네임·소개 편집
- 서버 재시작 후 계정·세션·조황 유지
- 다른 계정의 수정·삭제 거부, 변경 요청 출처 검사, 인증 시도 제한

데이터 파일은 `data/hit.sqlite`와 같은 디렉터리의 SQLite 보조 파일입니다. `data/`와 환경 파일은 GitHub 등록에서 제외합니다. 이메일은 내부 계정용이며 공개 API에는 반환하지 않습니다. 현재 공개 조회는 닉네임과 조황만 제공합니다.

## 개발 환경의 한계

현재 서버는 이 PC의 127.0.0.1에만 연결하며 공개 서비스로 배포하지 않았습니다. 로컬 HTTP 쿠키를 사용합니다. 공개 배포 시 HTTPS, Secure 쿠키, 실제 도메인 출처 설정, 운영용 인증·요청 제한, 모니터링 구성이 필요합니다.

최초 단계에서는 글 조황만 저장했으며 이후 사진·소통·운영·탈퇴와 [이메일 인증·재설정](11_EMAIL_AUTH.md)을 연결했습니다. 프로필 사진은 아직 미구현이며 실제 메일 발송·클라우드 계정은 연결하지 않았습니다.

## 데이터 구조·API

`users`(계정·프로필), `sessions`(만료 세션), `posts`(작성자·조황)를 SQLite에 저장합니다. 외래 키와 이메일 유일 제약을 사용합니다. 최초 버전 1에서 사진·소통 테이블을 버전 2로 추가했고, 현재 운영·탈퇴 관련 스키마는 버전 3입니다.

| 요청 | 용도 |
| --- | --- |
| POST /api/signup, /api/login, /api/logout | 가입·로그인·로그아웃 |
| GET /api/me | 현재 로그인 확인 |
| PATCH /api/profile | 내 프로필 수정 |
| GET /api/posts | 공개 목록; mine=1, fish, region, before 지원 |
| POST /api/posts | 조황 저장 |
| GET /api/posts/:id | 조황 상세 |
| PATCH, DELETE /api/posts/:id | 작성자만 수정·삭제 |

## 검증

`npm test`로 두 계정 간 권한 분리, 로그인 실패, 중복 가입, 세션 만료·로그아웃 무효화, 서버 재생성 후 기록 유지, 검색·페이지 분할, 잘못된 날짜·본문 크기·요청 출처·인증 시도 제한을 확인합니다.

브라우저에서 개발 검증 계정으로 가입하고 조황 작성 → 상세 → 새로고침 후 로그인과 기록 유지를 확인했습니다. 검증 기록은 실제 조황으로 오해하지 않도록 제목과 본문에 개발 검증이라고 표시했습니다. PC 대형 화면은 이 환경의 브라우저 크기 조절 기능이 없어 별도 시각 검증이 필요합니다.

## 개발 데이터 백업

서버를 정상 종료한 뒤 `data/` 폴더 전체를 다른 안전한 위치에 복사합니다. 복원도 서버가 종료된 상태에서 수행합니다. 데이터 파일에는 계정 정보가 있으므로 저장소에 올리지 않습니다. 자동 백업·복원 검증은 공개 배포 전 별도 작업입니다.

구현 근거: [Node.js SQLite](https://nodejs.org/docs/latest-v24.x/api/sqlite.html), [Node.js crypto](https://nodejs.org/docs/latest-v24.x/api/crypto.html).
