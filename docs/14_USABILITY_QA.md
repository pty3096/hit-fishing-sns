# 첫 버전 사용성 점검

## 수정 내용

| 확인한 불편 | 반영한 동작 |
| --- | --- |
| 지역 전체 명칭을 알아야 검색됨 | `강릉`처럼 일부 지역명·어종명으로 검색 |
| 상세에서 돌아오면 검색 조건이 사라짐 | 검색 조건을 화면 주소에 보존하여 뒤로 가기·새로고침에도 유지 |
| 검색·팔로잉·프로필의 빈 목록 안내가 같음 | 상황별 안내와 다음 이동 버튼 제공 |
| 사진을 넘길 수 있는지 알아보기 어려움 | 이전·다음 버튼, 사진 번호, 방향키 이동 추가 |
| 댓글을 입력한 다음 로그인·인증 요구 | 입력 전에 로그인·인증 상태와 이동 안내 제공 |
| 긴 입력과 작은 버튼이 모바일에서 불편 | 긴 닉네임 줄바꿈, 입력 글자 크기, 주요 버튼 최소 높이 보완 |
| 연결 문제를 이해하기 어려움 | 연결 오류 안내와 다시 시도 제공 |
| 페이지를 넘긴 뒤 키보드 위치를 찾기 어려움 | 본문 바로가기와 화면 이동 후 본문 초점 제공 |
| 더 보기 실패 후 버튼이 사라질 수 있음 | 오류 시 같은 버튼으로 다시 시도 가능 |

화면을 이동한 뒤 늦게 도착한 글·댓글 저장 응답이 다른 화면의 내용을 바꾸거나 원래 화면으로 강제로 돌아오지 않도록 일부 제출 흐름에도 확인 처리를 넣었습니다.

## 직접 확인한 화면

내장 브라우저에서 실제 화면 크기를 변경해 확인했습니다. 점검 후에는 원래 화면 크기로 되돌렸습니다.

| 크기 | 확인 내용 | 결과 |
| --- | --- | --- |
| 320×740 | 조황 상세·사진 영역·비로그인 댓글 안내 | 가로 넘침 없음 |
| 390×844 | 검색 입력·결과·하단 메뉴 | 가로 넘침 없음 |
| 1440×900 | 좌측 메뉴·중앙 검색·우측 안내의 3열 구성 | 가로 넘침 없음 |

이 검사는 브라우저 화면 크기 검사이며 실제 iPhone·Android 기기나 모든 브라우저의 검사를 대신하지 않습니다.

## 직접 확인한 흐름

- `강릉` 검색 → 조황 상세 → 브라우저 뒤로 가기 → 지역 입력과 결과 유지
- 없는 지역 검색 → 결과 없음 안내 → 검색 조건 지우기
- 검증용 사진 2장으로 조황 작성 → 다음 사진 → 2/2와 버튼 상태 변경 → 왼쪽 방향키 → 1/2
- 로그아웃 후 조황 상세 → 입력창 대신 로그인 안내
- Tab → 본문 바로가기 → Enter → 본문으로 초점 이동; 주소를 잘못된 화면으로 바꾸지 않음
- 서버 일시 종료 → 검색 → 연결 오류와 다시 시도 → 서버 재실행 → 다시 시도 → 같은 검색 조건으로 복구

조황은 실제 출조 정보로 오해하지 않도록 제목·본문·이미지에 개발 검증이라고 표시했습니다. 기존 사용자 자료를 삭제하지 않았습니다.

## 자동 검사

기존 계정·사진·소통·운영·인증 검사와 함께 부분 검색·특수 문자 처리, 검색 주소 보존, 작성 가능 상태, 갤러리 위치 계산을 추가하여 21개가 통과했습니다. 검색어의 `%`, `_`, 역슬래시는 검색용 와일드카드가 아니라 입력한 문자 자체로 처리합니다.

GitHub 자동 검사에는 테스트, 배포 이미지 빌드, HTTPS 프록시 설정 확인과 운영 컨테이너 실행 검사가 포함됩니다.

## 남은 범위

현재는 로컬 앱입니다. 실제 이메일 발송·공개 도메인·서버 연결, 실제 기기와 보조 기술을 사용한 접근성 검증, 외부 시범 사용자 검증은 아직 진행하지 않았습니다. 공식 로고·확정 디자인 전체 원본도 미확보입니다.

후속 0.7.0에서 [작성 중 글 보호](15_DRAFTS.md)를 추가했습니다. 사진 임시 저장은 지원하지 않습니다.
