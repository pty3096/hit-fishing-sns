# 고정 호스팅 전환 검토안 — 2026-11-20

상태: 사용자 검토용 제안. Render 계정 생성·GitHub 연결·유료 서비스 생성·배포·메일 발송은 아직 수행하지 않았습니다. 기존 Docker 구성과 SMTP 인증 기능을 사용하고, PC 임시 연결에 의존하지 않는 주소를 목표로 합니다.

## 검토 구성

| 항목 | 제안과 범위 |
| --- | --- |
| 실행 | Render의 Docker 웹 서비스 1개, 기존 Dockerfile 사용 |
| 접속 주소 | 서비스가 제공하는 고정 onrender.com HTTPS 주소. 별도 도메인 구매는 첫 연결에 필요하지 않음 |
| 저장 | SQLite·사진용 영구 디스크 1GB부터, HIT_DB를 해당 마운트 안에 지정. 단일 인스턴스 유지 |
| 초기 자료 | 새 빈 운영 DB로 시작. 개발/시범 계정·사진·메일·백업은 업로드하지 않음 |
| 앱 설정 | NODE_ENV=production, APP_ORIGIN=서비스의 정확한 HTTPS origin, MAIL_MODE=smtp, HIT_DB=영구 경로. 개발 메일함은 운영에서 비활성화 |
| 메일 | SMTP 서비스 계정·허용 발신 주소가 필요. SMTP_HOST/PORT/USER/PASS와 MAIL_FROM을 서비스의 비밀 환경 설정에 직접 연결 |
| 배포 | GitHub main의 검증된 커밋으로 수동 배포부터 시작. 자동 공개 배포·다중 인스턴스는 첫 연결에 포함하지 않음 |

## 비용 검토

Render 공식 Docker 호스팅 안내는 상시 실행 구성을 월 7달러부터 안내합니다. 공식 요금표의 영구 디스크는 GB당 월 0.25달러입니다. 이에 따라 1GB 디스크를 포함한 시작 예상은 월 7.25달러 수준이며, 실제 사용 요금·세금·환율·메일 서비스·초과 사용료는 별도이고 생성 화면의 최종 가격을 다시 확인해야 합니다. 가격을 확정 계약으로 취급하지 않습니다.

Free 웹 서비스는 영구 디스크를 사용할 수 없고 재시작·재배포 시 로컬 파일이 사라질 수 있어 현재 SQLite·사진 저장 구성의 실사용 경로로 제안하지 않습니다. 외부 DB/사진 저장소로 구조를 바꾸는 무료 대안은 별도 작업이며 무료 지속 운영을 보장하지 않습니다.

## 사용자 결정 뒤 수행할 작업

1. 사용자가 호스팅 비용 범위를 결정하고 Render에 직접 로그인합니다. 필요한 GitHub 저장소 연결 권한과 결제·약관 동의는 해당 화면에서 직접 확인합니다.
2. 서비스 이름·지역·영구 디스크·환경 설정을 서비스 생성 화면에서 구체화하고 실제 요금과 디스크 쓰기 권한을 확인합니다. 이 문서는 해당 환경에서 검증한 배포 완료본이 아닙니다.
3. SMTP 서비스 연결·발신 주소 인증을 완료합니다. 비밀번호나 API 키를 채팅·저장소에 올리지 않습니다. SMTP 설정이 없으면 기존 운영 모드가 시작을 거부합니다.
4. 실제 HTTPS·보안 쿠키·개발 메일 차단·가입 메일 수신·인증·재설정·글/사진 저장·재배포 후 자료 유지·백업 복원을 확인합니다.
5. 실제 운영자 지정, 이용 정책·문의 창구·개인정보 안내를 확정하고 공개 운영 범위를 결정합니다. 이 항목이 끝나기 전에는 출시 완료라고 표시하지 않습니다.

승인 전에는 요금이 발생하는 자원을 생성하지 않습니다. 비용을 승인하지 않으면 로컬 개발 검증을 유지하며 외부 접속 문제를 해결했다고 표시하지 않습니다.
